# Source map for scripts/import-win7-assets.sh.
# Format: <asset> <path-in-image-1> [TYPE/id]
#         CONTACT <path-in-image-1>
#         wallpapers/<Name> DIR <folder pattern>
#         gadgets/<Name> DIR <folder pattern>
#   <asset>          path under Assets/: icons/, cursors/, sounds/ or fonts/ + a plain name ending in .png, .wav or
#                    .ttf ([A-Za-z0-9][A-Za-z0-9._-]*), or wallpaper.jpg or start-orb; any other name is skipped
#                    ("unsafe asset name"). "start-orb" is special: it writes start-orb.png, start-orb-hover.png
#                    and start-orb-pressed.png from a 3-frame vertical strip.
#   <path-in-image>  path inside Windows 7 (image 1 of install.wim, or the tree root). May contain spaces. Letter
#                    case matters (Windows/System32/Display.dll).
#   TYPE/id          the PE resource inside that file: ICON/<group>, CURSOR/<group>, WAVE/<id>, BITMAP/<id>. Every
#                    icons/*.png or cursors/*.png line that names a .dll/.exe/.cpl needs one. <group> is the icon
#                    group's number, or its resource name when 7-Zip shows a name (ICON/IDI_APPICON: letters,
#                    digits and '_', matched exactly). ICON/? means "not chosen yet": the line is skipped and the
#                    file still gets a contact sheet to choose from. ICON/- means "this media has no such icon"
#                    (no icon resource, or the file is not on image 1): the line is skipped for good and the
#                    drawn icon stays.
#   CONTACT          make a contact sheet of that file even if no line takes an icon from it.
#   DIR              copy whole folders: every folder the pattern matches, in EVERY image of install.wim (merged),
#                    becomes Assets/wallpapers/<what the pattern's single '*' matched>/ with that folder's *.jpg,
#                    or, for gadgets/<Name>, Assets/gadgets/<what '*' matched>/ with the folder's *.png, *.jpg and
#                    *.gif at its top level, in images/ and in images/<folder>/ (same relative paths; no html, js,
#                    css or xml). Folder and file names must be plain; symbolic links are never followed.
# '#' at the start of a line or after a space or tab starts a comment. Trailing tags: K = an id already used
# before 2026-10-17; "chosen 2026-10-17" = read off labelled contact sheets of the user's own media.
# Contact sheets: Assets/_contact/<dll>-<group>.png (one per icon group, 48 px) and Assets/_contact/<dll>.png (all
# of a file's groups, labelled with their ids) for every file an ICON or CONTACT line names. If an icon looks
# wrong, find the right group there and edit the id on the matching line below. No code changes needed.
