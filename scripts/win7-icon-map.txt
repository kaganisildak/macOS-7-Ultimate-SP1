# Icon map for scripts/import-icons.sh (make import-icons SRC=<zip or folder of .ico files>).
# Format, one mapping per line ('#' after a space, or at the start of a line, begins a comment):
#   <imageres.dll icon id> <name>.png    the id is the number in an exported name: imageres-#3.ico is id 3
#   <dll>:<id>             <name>.png    another DLL's icon group: shell32:25 takes shell32-#25.ico (or
#                                        shell32-25.ico); the dll is the file name without .dll/.exe/.cpl, any case
#   <file>.ico             <name>.png    an icon file by name (any letter case), for packs of named icons
# Exported names: <dll>-#N.ico, <dll>-N.ico, #N.ico or N.ico (no dll part means imageres).
# <name>.png is written to Assets/icons/ (and the installed copy). Names are plain file names: letters, digits,
# '.', '-' and '_'. app-<bundle id>.png replaces that application's icon in the taskbar, Start menu, switcher
# and jump list.
# Icons whose id is not listed, from any DLL, go to Assets/_contact/<pack>/<dll>-<id>.png only, and all of them
# into one labelled sheet, Assets/_contact/<pack>.png, so you can look at them and add a line here; then re-run
# the import. Other .ico files not listed by name are skipped. No code changes needed. Entries missing from a
# pack are simply not imported. The ids are the same as in scripts/win7-asset-map.txt.
